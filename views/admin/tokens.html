API Documentation

All API requests require the X-API-Token header with your token.

1. Create Short Link (POST)

Create a new short link. Custom code is optional and will be auto-generated if not provided.

curl -X POST {{.BaseURL}}/api/v1/links \
-H "Content-Type: application/json" \
-H "X-API-Token: YOUR_TOKEN_HERE" \
-d '{"original_url": "https://example.com"}'

With custom code (spaces will be replaced with hyphens, supports `-` and `_`):

curl -X POST {{.BaseURL}}/api/v1/links \
-H "Content-Type: application/json" \
-H "X-API-Token: YOUR_TOKEN_HERE" \
-d '{"original_url": "https://example.com", "code": "my-custom-code"}'

2. Update Link Code (PUT)

Update the short code for an existing link. Only links created by your API token can be updated.

curl -X PUT {{.BaseURL}}/api/v1/links \
-H "Content-Type: application/json" \
-H "X-API-Token: YOUR_TOKEN_HERE" \
-d '{"original_url": "https://example.com", "code": "new-code"}'

Note: Code must be unique. Spaces in code will be automatically replaced with hyphens.

3. Delete Link (DELETE)

Delete a link by its original URL. Only links created by your API token can be deleted.

curl -X DELETE {{.BaseURL}}/api/v1/links \
-H "Content-Type: application/json" \
-H "X-API-Token: YOUR_TOKEN_HERE" \
-d '{"original_url": "https://example.com"}'

Code Format Rules:

  • Length: 4-20 characters
  • Allowed characters: letters, numbers, hyphens (`-`), and underscores (`_`)
  • Spaces are automatically replaced with hyphens
  • Code must be unique across all links
